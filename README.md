# 一生一城 · 张謇人生游戏

中文视觉小说网页游戏。玩家扮演张謇，从1894年状元转身走到1926年人生终章，在实业、教育、政治与地方建设之间作出选择。

[在线游玩](https://realInfiniteX.github.io/zhang-jian-life/)

故事按“事件 → 画面 → 配文帧”组织，包含66个事件、132个画面片段、247帧事件叙事。史实主线经过32个事件、162帧叙事（包含选择后果和终章），其中只设置15次关键抉择。序章16帧直接从荣当状元的金榜场面开始，随后展开翰林新身份、甲午战报与功名之后的取舍；早年读书、殿试和赴朝只作为回忆交代，读完后才出现第一次选择。

保留32个抉择节点，每个节点3个选项；共10个结局。连续选择“史实选择”形成15次抉择的主世界线。其余道路探索仕途、教育、稳健经营、合资、共和倡议、地方自治与债务危机。后续回到史实节点不消除此前的架空选择。

场景铺满整个屏幕，中年、晚年张謇立绘与配角、对白和选项叠放在画面中。结局为完整屏幕的终章海报，使用“实业兴邦”“书香门第”等主题标题，展示完整回望、最终状态与选择记录。四项状态以左下角小圆环显示：实业根基、教育薪火、公共信望、周转余力影响可选行动；数值仅表示游戏资源，不能用来量化历史评价。图片来源在“史料”入口查看。

## 游玩

点击“继续”或按Enter、空格、右方向键逐帧阅读；左方向键回看。事件之间更换场景，同一画面承载数帧配文，事件正文每帧约74—113字，补充具体处境、人物反应与前后因果。只有读到抉择时才显示选项，点击或按1、2、3作出选择。阅读与回看不改变资源，选择只计入一次影响。支持事件与选择回顾、回溯、本机逐帧自动存档、已发现结局收藏和全屏。旧版存档可迁移，保留已作出的选择与资源。手机使用纵向场景与对白布局。游戏无需登录、不上传存档；存档只在当前浏览器内有效。

## 配角互动

许掌柜（商股代表）、林先生（师范教员）和顾先生（立宪同人）分别出现在筹股、办学和立宪章节。角色轮流发言并同屏出现，当前说话者保持明亮，另一人物略微淡化。选择围绕厂约募股或短借抢工、师范与工场练习的经费次序、国会请愿的渠道与联署范围展开，后果继续回应配角的要求。

三位配角为戏剧合成角色，对话与具体会面属于游戏创作，不作为真实人物的言行史料；史实选择表示历史行动方向。

## 声音与轻微动态

原创五声音阶配乐有书斋、学堂、危机、终章四种编配，点击游戏控件后开始播放。右上“音乐”可分别开关BGM和事件音效、调节音量；偏好保存在当前浏览器，切换标签页时暂停。翻页、卷轴、报喜、机器与海战音效均由本地合成，不使用外部录音。配乐谱与音频调度在`dist/audio.js`，无需联网获取音乐。

演出包含缓慢推镜头、人物轻微呼吸与点头、两套配套手势的溶解过渡，以及海战时短暂轻晃。阅读和回看不会改变游戏资源；系统减少动态效果的偏好会关闭这些运动。

## 史料与图片

主要依据用户提供的《张謇》课程专题材料，并在每个节点的“史实对照”中提供核验与延伸阅读链接。原始文档未公开。独白、选项、具体决策过程及全部IF结局为游戏创作，不冒充历史引语。

史料列表、历史图片来源与许可可在游戏“史料与说明”中查看。张謇肖像和1915年大生外观来自用户材料中注明来源的Commons公有领域图片。2013年南通博物苑照片由猫猫的日记本摄，遵循CC BY-SA 3.0，原图未修改、仅按比例展示。

17张场景背景、4张张謇立绘（中年、晚年、致意、抬卷阅读）和3张配角立绘为内置image_gen生成的艺术演绎，完整提示词保存在`dist/assets/art-prompts.json`，由游戏直接提供阅读入口。人物参考历史肖像，场景不声称精确建筑复原。

## 本地开发与验证

运行环境：Node.js 22或更高版本。游戏运行本身不依赖第三方包；Playwright只用于开发验证。

```sh
npm ci
npm start
npm test
npx playwright install chromium
npm run test:ui
```

`npm start`默认在`http://127.0.0.1:4173/`服务`dist`。`PORT`可修改端口。游戏入口是`dist/index.html`，抉择数据在`dist/story.js`，事件、画面与配文帧在`dist/narrative.js`，纯状态规则在`dist/engine.js`，浏览器展示与本机存档在`dist/app.js`。

提交到main会触发GitHub Actions：先验证故事图、事件与帧序列、时间顺序、资源规则、逐帧存档回溯和全部节点/选项/结局的可达性，再在桌面、手机、小屏手机运行浏览器流程，并验证音乐控制、音频实际波形、手势与减少动态效果；验证通过才将`dist`发布到GitHub Pages。

支持WebMCP的浏览器可读取人生状态、作出选择和继续人生；工具复用可见界面的规则。不支持该能力的浏览器仍可正常游玩。
