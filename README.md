# 一生一城 · 张謇人生游戏

中文视觉小说网页游戏。玩家扮演张謇，从1894年状元转身走到1926年人生终章，在实业、教育、政治与地方建设之间作出选择。

[在线游玩](https://realInfiniteX.github.io/zhang-jian-life/)

故事按“事件 → 画面 → 配文帧”组织，包含66个事件、132个画面片段、247帧事件叙事。史实主线经过32个事件、162帧叙事（包含选择后果和终章），其中只设置15次关键抉择。序章16帧依次展开寒窗、殿试、金榜消息与甲午战事，读完后才出现第一次选择。

保留32个抉择节点，每个节点3个选项；共10个结局。连续选择“史实选择”形成15次抉择的主世界线。其余道路探索仕途、教育、稳健经营、合资、共和倡议、地方自治与债务危机。后续回到史实节点不消除此前的架空选择。

场景铺满整个屏幕，中年、晚年两套张謇立绘与独白、选项叠放在画面中。四项状态以左下角小圆环显示：实业根基、教育薪火、公共信望、周转余力影响可选行动；数值仅表示游戏资源，不能用来量化历史评价。图片来源在“史料”入口查看。

## 游玩

点击“继续”或按Enter、空格、右方向键逐帧阅读；左方向键回看。事件之间更换场景，同一画面承载数帧短配文。只有读到抉择时才显示选项，点击或按1、2、3作出选择。阅读与回看不改变资源，选择只计入一次影响。支持事件与选择回顾、回溯、本机逐帧自动存档、已发现结局收藏和全屏。旧版存档可迁移，保留已作出的选择与资源。手机使用纵向场景与对白布局。游戏无需登录、不上传存档；存档只在当前浏览器内有效。

## 史料与图片

主要依据用户提供的《张謇》课程专题材料，并在每个节点的“史实对照”中提供核验与延伸阅读链接。原始文档未公开。独白、选项、具体决策过程及全部IF结局为游戏创作，不冒充历史引语。

史料列表、历史图片来源与许可可在游戏“史料与说明”中查看。张謇肖像和1915年大生外观来自用户材料中注明来源的Commons公有领域图片。2013年南通博物苑照片由猫猫的日记本摄，遵循CC BY-SA 3.0，原图未修改、仅按比例展示。

17张场景背景与2套人物立绘为内置image_gen生成的艺术演绎，完整提示词保存在`dist/assets/art-prompts.json`，由游戏直接提供阅读入口。人物参考历史肖像，场景不声称精确建筑复原。

## 本地开发与验证

运行环境：Node.js 22或更高版本。游戏运行本身不依赖第三方包；Playwright只用于开发验证。

```sh
npm ci
npm start
npm test
npx playwright install chromium
npm run test:ui
```

`npm start`默认在`http://127.0.0.1:4173/`服务`dist`。`PORT`可修改端口。游戏入口是`dist/index.html`，抉择数据在`dist/story.js`，事件、画面与配文帧在`dist/narrative.js`，纯状态规则在`dist/engine.js`，浏览器展示与本机存档在`dist/app.js`。

提交到main会触发GitHub Actions：先验证故事图、事件与帧序列、时间顺序、资源规则、逐帧存档回溯和全部节点/选项/结局的可达性，再在桌面、手机、小屏手机运行浏览器流程；验证通过才将`dist`发布到GitHub Pages。

支持WebMCP的浏览器可读取人生状态、作出选择和继续人生；工具复用可见界面的规则。不支持该能力的浏览器仍可正常游玩。
